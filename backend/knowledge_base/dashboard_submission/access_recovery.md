# Dashboard & Submission: Login and Access Recovery

If dashboard access fails:
1. use Forgot Password and complete OTP verification
2. verify the registered email used during onboarding
3. wait up to 15 minutes after account activation
4. clear browser cache and retry

Common failure reasons:
- expired reset links
- incorrect dashboard alias
- blocked OTP delivery

Escalate access issues if 3 retries fail or MFA cannot be completed.
