# Dashboard & Submission: Failed Manuscript Submission Handling

Submission failures usually occur due to:
- unsupported file formats
- oversized uploads
- missing metadata fields
- cover image resolution below requirement

First-line support checklist:
- confirm accepted file formats
- validate metadata completeness
- retry submission after cache reset
- verify ISBN request state

Escalation criteria:
- repeated failure after 2 retries
- backend validation error persists
- submission marked failed_submission in workflow
