# Challenge Overview: Identity Ambiguity in Author Support

Authors often interact using different identity signals:
- primary email
- WhatsApp number
- Instagram handle
- dashboard username
- pen name

Typical ambiguity patterns:
- one email shared by brand teams
- similar pen names across multiple authors
- outdated phone numbers in profile records

Escalation guidance:
- confidence > 90%: auto-link profile
- confidence 70%-90%: manual verification required
- confidence < 70%: reject and request additional identifiers

When multiple author records are possible, support should request one additional verified signal before publishing-sensitive actions.
